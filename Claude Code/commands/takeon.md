---
description: Take on the task in HANDOFF.md, logging progress in it so several chats can work on it at once
---

Read HANDOFF.md in the current project and do the task in it. Other chats may be working on the same HANDOFF.md at the same time, so keep a running log in the file:

1. Before starting, re-read HANDOFF.md from disk. Its "Progress" section lists what other chats have claimed or finished. Skip anything marked "in progress" or "done" by another chat.
2. Claim your part first: add a line to the "Progress" section (create the section at the end of the file if it is missing) in the form `- [in progress, <date> <time>, chat <short name>] <the item or step you are taking>`. Pick a short chat name (e.g. the first task word plus the time). Write the file before you do any work. If the task has numbered items, claim one item at a time.
3. When your part is done, change that line to `- [done, <date> <time>, chat <short name>] <item>: <one line on what changed and where>`. If you stop before it is done, change it to `[stopped, ...]` and say what is left.
4. Before every write to HANDOFF.md, re-read it from disk and only change your own lines, so you never overwrite another chat's entries. Never rewrite the task text or other chats' lines.
5. Append a short "Result" section only when the whole task is finished (all items done), or when the user ends your part; otherwise the Progress lines are the record.
